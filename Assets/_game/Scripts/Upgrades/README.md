# Экран улучшений

`BandolierUpgradeScreen` создаёт интерфейс; `UpgradeSelection` хранит выбор предложения/гнезда и запрос подтверждения. `UpgradePresentation` рендерит существующую анимацию патронташа и предметы в RenderTexture отдельной камеры (слой 30, сцена презентации расположена далеко от арены). Ресурсы загружаются из `Resources/Upgrades/PresentationAssets.asset`.

- Экран открывается между волнами. Первая стадия — патрон из трёх, вторая — модуль из трёх.
- Патронташ справа занимает 58% ширины. Выбор предложения запускает движение поверхности/царапин и небольшое покачивание модели.
- Без выбранного предложения нажатие на гнездо приподнимает патрон; второе гнездо меняет патроны местами. Модули остаются на местах.
- Предложение и гнездо можно выбирать в любом порядке. До подтверждения барабан не меняется; отмена/Esc сбрасывают выбор.
- После патрона экран остаётся открытым для модуля и перестановки. Подтверждение модуля завершает экран и возобновляет бой.
- Гнездо показывает отдельные подсказки патрона и модуля через StackedUpgradeTooltip. Предложения используют обычный TooltipTrigger.

`UpgradeAssetsAuthoring.BuildAssets` экспортирует презентацию из BandolierPreview, создаёт библиотеку, материал/меш скобы и начальную подгонку ранее не использовавшихся наконечников. Ручная сцена и шесть уже подогнанных спрайтов сохраняются. Повторная сборка перезаписывает генерируемые resources. Визуал определяется AmmoItem.Archetype.VisualIndex: дополнительный поджог или холод не меняет тип и наконечник пули. Обычный патрон без типа использует Plain.

Проверка: `-batchmode -executeMethod BandolierUpgradeValidation.Run` с графическим backend Unity. Проверяются выбор в обоих порядках, поднятие, перестановка, shader spin, отмена/подтверждение, пауза и две стадии; рендеры сохраняются в уникальную папку `.utmp/Artifacts/upgrade-*`. `FiveWaveRunValidation.Run` проверяет весь забег и восемь выборов наград. Для offscreen-презентации в Unity 2022.3 не применять `-nographics`: null renderer в этом режиме может аварийно завершаться.

Скоба `Art/Upgrades/ModuleClip.png` сгенерирована встроенным image_gen. Полный промпт и происхождение — в README папки графики.
