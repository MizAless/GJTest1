# Звуковой проход прототипа

- `Resources/Audio/GameAudioBank.asset` — редактируемый банк: 16 событий, 46 WAV-вариантов, мастер-громкость, громкость каждого события, диапазон питча, минимальный интервал, лимит голосов и приоритет. Меньшее число приоритета означает более важный звук.
- API: `GameAudio.Play(SoundCue.Shot, worldPosition)`; для интерфейса позиция не нужна. Отложенный звук поддерживает `delay:` и не зависит от timeScale. `pitchScale:` масштабирует скорость составного звука патронташа под длительность анимации. В edit mode воспроизведения нет.
- Сервис создаётся один раз на сцену по первому событию, имеет фиксированный пул из 28 AudioSource и удаляется со сценой. Не добавлять новый AudioSource на каждое попадание. События не повторяют один и тот же вариант подряд; отдельный System.Random не меняет последовательность игрового UnityEngine.Random.
- Боевые частые события имеют небольшую громкость, ограничения по времени/одновременным голосам. Стоны врага допускаются на каждом третьем прямом попадании, начиная с первого, не чаще 0,8 секунды на врага и дополнительно ограничены общим банком. DoT не воспроизводит звук прямого попадания на каждом тике. Веер играет один выстрел на выпуск, а не на каждый снаряд.
- Взрыв звучит в `CombatEffects.Area`, один раз на логическое событие, не из отдельных систем частиц. Рикошет — при действительном перенаправлении пули к следующей цели. При смерти не добавляется ещё один стон боли этой же цели.
- Патронташ: запуск в BandolierPreview при начале воспроизведения после задержки, не при Scrub или импорте. Звук содержит рывок ткани, кожу, приглушённый металл и два низких акцента; базовая длительность анимации 1,35 с. Перестановка патронов звучит в BulletContainer.SwapCartridges; выбор карточки и подтверждение — в RunUI/RunDirector. Другие будущие экраны могут использовать те же Swap/Select.
- Удары по герою и его голос — отдельные события. По явному разрешению пользователя добавлен PlayerHealth: 100 HP, контактный урон врага 10 с расстояния 0,8, интервал атаки 1,1 с, общая неуязвимость 0,7 с. Замороженный враг не атакует. Урон не наносится во время наград или завершённого забега. HP сохраняются между волнами, после перезапуска восстанавливаются. Пока нет лечения/дополнительных правил.
- RunDirector.Lose останавливает забег, показывает экран поражения и ставит игру на паузу. У смерти героя свой звук; джингл поражения начинается через 0,45 с. Победы волны и всей игры разделены. Аудио продолжает работать на паузе.
- AudioSafetyLimiter автоматически добавляется к AudioListener: стереосвязанный быстрый контроль пиков до 0,88 с плавным восстановлением, без выделений памяти в аудиопотоке. Это защитный предел для случайного наложения, а не автоматическое увеличение громкости.
- Прослушивание в редакторе: Play → `Tools > Prototype > Audio > Sound palette (Play Mode)`. Любое событие можно послушать кнопкой без убийства героя. Для настройки открыть банк и менять его параметры. `Create or update audio bank` заново назначает подготовленные значения и сбрасывает ручную подстройку банка.
- Исходники, авторы и лицензии: `Assets/ThirdParty/PrototypeAudio/README.md`. DSP-рецепты: `Tools/Audio/build_audio.py`. Часть вариантов получена обработкой одной записи, а не отдельными дублями; выстрелы и удары используют разные исходные дубли.
- Проверка: `GameAudioValidation.Run` (Editor/batchmode). Проверяются реальные выстрелы/попадания/рикошеты, контактный урон, неуязвимость, поражение, аудио на паузе, раскрытие патронташа, лимиты пула, неизменность игрового RNG, пять волн и финальная победа. Изолированный проверочный проект: `ArtValidationLocal/`.
