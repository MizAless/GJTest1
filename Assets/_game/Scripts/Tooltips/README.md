# Подсказки предметов

- Префаб: `Assets/_game/Resources/UI/ItemTooltip.prefab`. Стиль и заголовки секций редактируются прямо в Unity. Поля и ссылки находятся на `TooltipView`; рамка, отступы, шрифты и цвета — на дочерних объектах. Меню пересоздания префаба сбрасывает ручные изменения его оформления.
- Просмотр: `Assets/_game/Scenes/TooltipPreview.unity`, Play и наведение на четыре карточки. Левый край проверяет переключение направо; модуль — перенос тегов. Демонстрационные имплиситы не меняют боевые свойства.
- Реальное подключение: `RunUI` добавляет `TooltipTrigger` к шести слотам барабана, трём наградам и шести гнёздам установки. Наведение читает актуальный предмет и модуль гнезда; переход между экранами скрывает подсказку.
- Для другого uGUI-объекта: добавить `TooltipTrigger` на объект с Graphic, участвующим в raycast, и заполнить Content в инспекторе. Нужны Canvas с GraphicRaycaster и EventSystem. Из кода можно назначить `Bind(() => content)` или вызвать `TooltipPresenter.For(canvas).Show(owner, content, screenPointer)`; Hide требует тот же owner. Для объектов вне Canvas использовать прямой API presenter из своего обработчика наведения.
- `TooltipContent` универсален: Title, Subtitle, Accent, Tags, Intrinsic, Properties[], Triggers[]. Пустые секции скрываются, плашки тегов переиспользуются. Rich Text поддерживается в описаниях. `Intrinsic` — собственное, неизменяемое свойство типа; оно может само быть триггером, как у разгонной пули.
- `AmmoTooltipContent` берёт имплисит из `AmmoItem.Archetype.IntrinsicDescription`, а дополнительные свойства и триггер — из самого предмета. Теги учитывают врождённые состояния. Модули не получают тип пули. Обычная пуля без имплисита скрывает блок. Не дублировать врождённый эффект в случайных свойствах.
- Следование использует экспоненциальный Lerp на unscaledDeltaTime, включая паузу. Настройки Cursor Gap / Screen Margin / Follow Speed доступны на TooltipPresenter корневого Canvas в Play. Первое появление позиционируется сразу. Проверяются оба боковых края и вертикальные границы; слишком длинная подсказка равномерно уменьшается до доступного размера, не обрезается.
- Префаб не перехватывает raycast или клики. Отдельный presenter используется на каждом корневом Canvas. Поддержаны Screen Space Overlay и Screen Space Camera с назначенной worldCamera. Координаты API — экранные пиксели; размеры и зазоры — единицы CanvasScaler.
- Проверка: `TooltipValidation.Run` в Unity Editor/batchmode. Артефакты пишутся в `Artifacts/tooltip-validation.txt` и `Artifacts/tooltip-preview.png` текущего проверочного проекта.

Визуальный референс: [скриншот Dicewood со всплывающими подсказками](https://shared.fastly.steamstatic.com/store_item_assets/steam/apps/3393850/70f7743243d73bd3e65bc3d4840a04706c4a7805/ss_70f7743243d73bd3e65bc3d4840a04706c4a7805.1920x1080.jpg), [официальная страница](https://store.steampowered.com/app/3393850/). Скриншот использован только для просмотра; в ассеты проекта не включён. Тёмная панель, тонкая рамка и цветовые акценты собраны штатными компонентами uGUI.

На экране патронташа (Scripts/Upgrades) StackedUpgradeTooltip использует два экземпляра того же ItemTooltip.prefab: патрон сверху, отдельный модуль снизу с зазором 8. При отсутствии модуля вторая плашка скрыта. Общая группа следует за курсором, ограничивается Canvas/safe area и при необходимости уменьшается целиком. UpgradeSlotHover обслуживает всё гнездо, включая петлю и скобу. HUD по-прежнему использует существующий объединённый адаптер; содержимое модели AmmoItem не изменилось.

Имплисит оформлен отдельной подложкой над дополнительными свойствами. Внутри только сам эффект, без поясняющего заголовка и подписи о неизменяемости. Блок целиком скрывается без Intrinsic. Изменения воспроизводятся через TooltipAuthoring.CreatePrefab. Это оформление не превращает случайные свойства AmmoItem во врождённые.
