# Пиксельный интерфейс и волна текста

`PixelUiTheme` устанавливается при запуске автоматически и назначает uGUI Text шрифт `Resources/Fonts/m6x11cyrillic.ttf`. Размер, цвет, rich-text разметка и логика кнопок сохраняются. Атлас шрифта использует Point; ресурсы и авторство описаны в `Resources/Fonts/README.md`.

`PixelCanvasWatcher` отмечает изменения иерархии Canvas, чтобы новые подписи урона и тултипы тоже получали шрифт. Панели `Reward screen` (текущий экран) и `Bandolier upgrades` (экран из параллельной задачи) автоматически получают маркер `UpgradeTextMotionScope`. Поэтому для подключения не нужно менять RunUI и конфликтовать с его переработкой в другом worktree.

Для панели с другим именем достаточно добавить на её корень `UpgradeTextMotionScope`. На её дочерние Text автоматически устанавливается `WavyUpgradeText`; можно менять Amplitude, Speed и Phase Per Glyph на маркере. По умолчанию амплитуда — 1,5 единицы Canvas, скорость — 2,3 радиана/с, сдвиг фазы на букву — 0,55. Вне апгрейдов шрифт тоже пиксельный, но текст не качается.

`WavyUpgradeText` смещает вверх/вниз целые квады видимых символов по синусоиде, не Transform текста. Цвета и UV не меняются, теги `<color>` и кириллица сохраняются. Используется unscaledTime: анимация работает, когда выбор награды ставит игру на паузу.

Проверка: Unity batchmode, `-executeMethod PixelUiValidation.Run`. Проверяет русские буквы и Ё/ё, цвета/UV, движение на паузе, динамически созданную панель нового экрана, направление HP и состав первой волны. Рендеры — `.utmp/Artifacts/pixel-ui-wave-a.png` и `pixel-ui-wave-b.png`.
