## Casing.png

Create a harmless fictional inventory sprite for a pixel-art roguelike videogame: one empty golden brass cartridge casing, WITHOUT any projectile. This is a stylized game UI asset, no people, no action, no violence or real-world instructions. Upright front orthographic view. Reusable straight cylindrical gold body with a slightly wider flat rim at the bottom, flat horizontal open top lip, dark brown pixel outline, chunky pixel clusters, bright upper-left highlight. Match the reference's warm pixel-art rendering. Width to height about 1:2.3. Entire empty casing visible, centered on genuinely transparent background. No leather loops, no straps, no text, no scenery, no external glow or cast shadow. The open top is a straight horizontal socket for separately drawn interchangeable fantasy tips. Only the common empty casing, not a complete cartridge.
