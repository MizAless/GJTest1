# Модульные патроны

Одна общая гильза Casing.png и девять сменных наконечников *Tip.png. Сгенерированы встроенным imagegen для пиксельного роглайка. Пиксели PNG не редактировались; прозрачность сохранена.

## Сборка

- Использовать одну и ту же Casing.png для всех видов.
- Наконечники: Plain (обычная), Needle (игла), Lava (лава), Ice (ледяная), Accelerator (разгонная), Fan (расширяющая), Conductor (проводящая), Link (связующая), Ricochet (рикошетная).
- В .meta настроены отдельные Pixels Per Unit и Custom Pivot. Масштаб определяется шириной посадочного основания, а не общей высотой.
- Для SpriteRenderer совместить позиции гильзы и наконечника и оставить одинаковый Transform scale. Гильза должна рисоваться поверх основания наконечника: например Sorting Order 1 у гильзы и 0 у наконечника.
- Ширина корпуса гильзы — 1 условная единица; посадочного основания наконечника — 0,8. Вся сборка масштабируется общим родителем.
- Наконечник слегка входит в горлышко, чтобы передний бортик скрывал стык. Общая длина патрона зависит от наконечника.
- Assembly.json хранит размеры, границы непрозрачного силуэта, ширину посадки и настроенные pivot/PPU. Для MeshRenderer нужно использовать эти точки и масштаб явно: он не применяет настройки SpriteRenderer автоматически.

Сцена BandolierPreview и боевые свойства в рамках этой генерации не изменялись. Это отдельный набор для последующей сборки. Точные промпты — в PROMPTS.md.
