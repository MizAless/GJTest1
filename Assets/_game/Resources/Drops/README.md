# Настройка выпадения свойств

Рабочая таблица: `Assets/_game/Resources/Drops/AmmoDropTable.asset`.
Откройте её в Inspector. Она автоматически используется для стартовых предметов
и обеих стадий наград. Пересборка сцен или префабов не нужна.

- `Rarities`: вес редкости, число свойств и вероятность дополнительного триггера.
- `Properties`: тип свойства, относительный вес, разрешение для патронов/модулей
  и стартовой выдачи. Каждое свойство выбирается не более одного раза на предмете.
- `Tiers`: название T1/T2/… для удобства настройки, собственный вес, допустимые
  редкости, разрешение для старта и включительный диапазон Minimum/Maximum Value.
- `Triggers`: тип триггера, относительный вес, допустимые редкости и тип предмета.

Сначала выбирается редкость. Для каждого свойства отдельно выбирается его тип
по весам доступных типов, затем тир по весам доступных тиров, затем значение
равномерно внутри диапазона. Веса не обязаны суммироваться до 100:
веса рикошета 100 и пробития 300 дают шансы 25% и 75%, если доступны только они.
Веса тиров T1=70, T2=25, T3=5 работают отдельно внутри выбранного свойства.
Недоступные тиры исключаются перед нормализацией. Тип без доступных тиров
не участвует в выборе. Вес 0 отключает тип/тир/триггер/редкость.

Для точного значения задайте одинаковые Minimum/Maximum Value.
Снаряды и заряды состояний используют целые значения; множители урона — проценты:
25 означает ×1,25. Overload — переключатель: значение 1 включает его.
Нулевая сила разрешена, но не даёт видимого эффекта; для отключения используйте вес 0.
Триггер выбирается отдельно после свойств с вероятностью Trigger Chance редкости.

Начальные настройки: редкости 55/30/12/3, число свойств 1/2/3/4,
шанс триггера 0/55/55/55%. Тиры обычно дают 1/2/3 заряда или соответствующие
ступени процентов; T2 доступен с Rare, T3 с Epic. Разветвление и перегрузка
имеют один тир. Все типы свойств имеют одинаковые веса. Это исходный баланс,
а не ограничение системы. Старт всегда Common, одно свойство без триггера;
в исходной таблице для старта доступны только десять поведений/состояний и T1.

Если доступных типов меньше требуемого количества, предмет получает меньше
свойств. Если нет ни одной доступной редкости или свойства, генератор сообщает
ошибку конфигурации вместо скрытого перехода на значения, зашитые в код.

Создать другую таблицу: Create → Prototype → Ammo drop table.
Для использования в забеге замените содержимое рабочего ресурса; дополнительная
таблица сама по себе не переключает генератор. Для программной проверки можно
передать её в `AmmoGenerator.Generate(table, module, starter)`.
Проверка: Unity batchmode `-executeMethod AmmoDropValidation.Run`.
