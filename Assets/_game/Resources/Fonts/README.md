# m6x11cyrillic

Авторы: Daniel Linssen (m6x11/m6x11plus) и Natto Games (расширение кириллицы).

Источник и условия: https://nattogames.itch.io/m6x11cyrillic
Исходное семейство: https://managore.itch.io/m6x11

Автор разрешает бесплатное использование с указанием авторства: "free to use with attribution (by Daniel Linssen and Natto Games)". При публикации игры добавить эти имена в титры. Шрифт скачан с официальной страницы автора без изменения TTF. Поддерживает русские буквы, включая Ё/ё. Рекомендуемые автором чёткие размеры: 16, 32, 48 и т.д.

Цвет текста и теги <color> задаёт uGUI, а не TTF. WavyUpgradeText меняет только координаты вершин и сохраняет цвета и UV.
